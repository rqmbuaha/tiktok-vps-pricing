## 为什么便宜的 VPS 做 TikTok 会 0 播放

TikTok 的风控对 IP 大致分三档，这个判断标准不只适用于 WePC，任何做 TikTok 的 VPS 都一样。

**第一档，机房 IP**。归属地显示为某个数据中心或云服务商，平台判定为非真人环境的概率最高，限流和封号都常见。几十块一年的廉价 VPS 基本都在这一档。

**第二档，原生 IP**。IP 的注册归属地和机房实际所在国一致。机房在德国、whois 显示德国，这就是原生 IP，平台会当作当地正常用户处理。这是做 TikTok 的及格线。WePC 的德国、韩国、日本、新加坡、越南、阿联酋几款都在这一档。

**第三档，住宅 IP / 双 ISP**。这类 IP 的归属显示为某家宽带运营商，观看者看到的就是一个家庭宽带地址。双 ISP 指同时具备两个运营商属性，抗风控能力更强。WePC 的洛杉矶 9929、英国、泰国属于这一档或接近这一档。这类方案的价格通常也最高。

买完之后自己验一遍：上 ipinfo.io 查 IP，类型显示 Residential 或 ISP 才算过关，显示 Hosting 就是机房 IP。这一步比看商家宣传页管用。

需要说清楚的是，住宅 IP 降低的是被判定为机器的概率，不能保证账号一定不被封，更不能保证有播放量。内容、时区设置、一号一 IP、新号先养三到五天再发内容，这些同样影响结果。资料中提到的“换了双 ISP 之后账号权重提升”之类的说法，都出自推广文里的转述，没有独立来源，不能当作效果承诺看。

**月付能退款吗？**

资料口径不统一，30 天仅限严重质量问题是一种说法，三天内分级退款是另一种。稳妥做法是买之前先在官网条款页或问客服确认当前版本，不要按任何一方的说法做预算。

**买一个月够测试吗？**

够验证三件事：IP 类型是不是 Residential、国内到你所在地区的延迟、TikTok 环境能不能正常起号。三件事都过了再谈年付。一个月不足以验证长期稳定性，但足以排除明显不合适的节点。

**1TB 流量够不够？**

纯短视频运营够。直播按码率算，2Mbps 一小时约 0.9GB，4Mbps 翻倍，流量是双向合计，超了限速不停机。做直播或多账号，直接看 2TB 的档。

**住宅 IP 是不是一定不封号？**

降低被判定为机器环境的概率，不保证结果。账号能不能起来，IP 只占一部分。
